# Object-Detection-Using-YOLO
Deteksi objek berbasis deep learning yang memproses seluruh citra sekaligus dalam satu kali jalan (one-stage detector). YOLO membagi gambar jadi kisi-kisi untuk memprediksi bounding box dan probabilitas kelas secara real-time, cepat, dan presisi tinggi. Praktis buat aplikasi live video tracking.
